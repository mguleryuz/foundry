# Project Brief: Foundry-based Smart Contract Development

## Project Overview

This project uses Foundry, a modern Ethereum development toolkit written in Rust, to develop smart contracts for token issuance and sale orchestration. The project appears to focus on creating ERC20 tokens with customizable properties and managing token pre-sales.

## Core Components

1. **ERC20Issuance_v1**: A contract for issuing capped ERC20 tokens with whitelist-gated mint/burn functionality
2. **PreSaleOrchestrator_v1**: A contract for managing token pre-sales (currently in development)

## Project Goals

- Develop secure, auditable smart contracts for token issuance
- Implement controlled token distribution mechanisms
- Create a flexible pre-sale system for token offerings
- Ensure compatibility with multiple Ethereum networks (Sepolia, Optimism Sepolia)

## Technical Requirements

- Smart contracts written in Solidity (v0.8.23)
- Development using Foundry's toolchain (Forge, Cast, Anvil)
- Support for multiple test networks
- Integration with OpenZeppelin contract standards

## Project Scope

- Development of core token issuance contracts
- Implementation of pre-sale orchestration functionality
- Comprehensive testing and security validation
- Deployment to test networks (Sepolia, Optimism Sepolia)

## Success Criteria

- Fully tested and auditable smart contracts
- Successful deployment to test networks
- Proper documentation of contract interfaces and functionality
- Secure implementation of token issuance and sale mechanisms
